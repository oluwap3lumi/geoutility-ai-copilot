## Upload handoff

1. Sign in to <https://plugins.qgis.org/> with the project owner's OSGeo account.
2. Choose **Add a new plugin** and upload `geoutility_copilot.zip`.
3. Review the imported metadata and submit version 0.3.2 for approval.
4. Record any automated validator or reviewer feedback in a GitHub issue before changing the
   package. QGIS requires each uploaded metadata version to be unique.

The upload cannot be completed through GitHub authentication; the official repository requires an
OSGeo identity and performs its own review/approval workflow.
